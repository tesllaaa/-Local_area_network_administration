5. Ответы на контрольные вопросы
Что такое Network Address Translation (NAT)?
Network Address Translation (NAT) — это механизм преобразования IP-адресов транзитных пакетов, проходящих через маршрутизатор. Чаще всего он используется для того, чтобы позволить множеству устройств в локальной сети с "серыми" (внутренними) IP-адресами выходить в Интернет, используя один или несколько "белых" (внешних) IP-адресов.

Как определить, находится ли узел сети за NAT?
Самый простой способ — сравнить IP-адрес, назначенный сетевому интерфейсу компьютера, с публичным IP-адресом, который видят серверы в Интернете. Для этого можно посмотреть IP-адрес в настройках сети ОС (командой ipconfig в Windows или ip a в Linux), а затем зайти на любой сайт, показывающий публичный IP (например, 2ip.ru или ifconfig.me). Если адреса не совпадают, значит, узел находится за NAT.

Какое оборудование отвечает за преобразование адреса методом NAT?
За преобразование адресов методом NAT отвечает пограничное сетевое устройство, которое соединяет локальную сеть с внешней (например, с Интернетом). Как правило, это маршрутизатор (роутер) или специализированный межсетевой экран (firewall).

В чём отличие статического, динамического и перегруженного NAT?

Статический NAT (Static NAT): Устанавливает постоянное соответствие "один к одному" между внутренним и внешним IP-адресом. Используется для того, чтобы сделать внутренний ресурс (например, веб-сервер) доступным извне.
Динамический NAT (Dynamic NAT): Преобразует внутренний IP-адрес в один из доступных IP-адресов из пула внешних адресов. Соответствие создается временно, на время сессии. Количество одновременных подключений ограничено размером пула внешних адресов.
Перегруженный NAT (NAT Overload или PAT - Port Address Translation): Это самый распространенный тип. Он позволяет множеству устройств с внутренними IP-адресами использовать один внешний IP-адрес для выхода в Интернет. Для различения сессий разных устройств используется дополнительный механизм трансляции номеров портов.
Охарактеризуйте типы NAT.

Статический NAT (SNAT):
Принцип: 1:1 (один внутренний IP -> один внешний IP).
Характеристика: Отображение является постоянным и настраивается вручную. Обеспечивает доступ из внешней сети к конкретному хосту во внутренней сети.
Применение: Публикация серверов (веб, почтовых и т.д.), расположенных в локальной сети.
Динамический NAT (DNAT):
Принцип: N:M (N внутренних IP -> M внешних IP из пула, где N >= M).
Характеристика: Отображение создается динамически при установлении сессии. Внутренний IP-адрес получает временный внешний IP из пула свободных адресов. Не обеспечивает доступ извне, только изнутри-наружу.
Применение: Используется в сетях, где количество пользователей, одновременно выходящих в интернет, не превышает количество выделенных внешних адресов, но закреплять адрес за каждым нецелесообразно.
Перегруженный NAT (PAT/NAT Overload):
Принцип: N:1 (множество внутренних IP -> один внешний IP).
Характеристика: Самый эффективный с точки зрения экономии адресов. Использует не только IP-адреса, но и номера TCP/UDP портов для идентификации каждой сессии. Маршрутизатор подменяет пару (source_IP:source_port) на (public_IP:new_port).
Применение: Подавляющее большинство домашних и офисных сетей для предоставления доступа в Интернет всем устройствам.
